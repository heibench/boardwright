# Test library for `LIBS`

A stand-in for a private part library: one symbol (`Custom:MYLDO-3.3`) and one
footprint (`Custom:MY_SOT-23-5`), copied from KiCad's stock AP2112K-3.3 and
SOT-23-5 and renamed, so nothing here exists under that name in the stock
libraries. `boards/customlib_test` builds against it.
